## Рабочее пространство web-product

[web-product](web-product/README.md) — интерфейс CoreTeams v9.2 (кандидат B), подключённый к backend через контракт V2 (`/api/v2`, реализация — `backend/api/product.py`). Это основной интерфейс: в docker-стеке он открывается на `/` (вход и регистрация — в нём же), свободный чат с документами — на `/chat/`. Проекты, созданные в прежнем интерфейсе v9, показываются в разделе «Проекты из прежнего интерфейса» только для чтения.

## Файлы, созданные агентом

Исходные байты каждого файла, который агент создал или изменил за время работы (через Write или скриптом, включая docx, xlsx, pdf и картинки), backend кладёт в S3-совместимое хранилище — в docker-стеке это SeaweedFS (сервис `s3`, ключи `S3_ACCESS_KEY`/`S3_SECRET_KEY` в `.env`). В базе остаются путь, sha256, тип и текстовое превью. Скачать файл можно в рабочем пространстве (кнопка «Скачать файл» у версии), в свободном чате и через `GET /api/runs/{run_id}/events/{seq}/file`. Без `S3_ENDPOINT_URL` хранилище выключено: текстовые файлы скачиваются из базы, бинарные — нет.
