## Изменение

В `web-demo/git-storage.js` поиск коммита по трейлеру `Operation-Id` ограничен началом и концом строки. Запрос теперь сопоставляется только с полным значением трейлера и не принимает ID, являющийся префиксом другого ID в любую сторону.

Формат Git-трейлеров и коммитов не изменён. Проверка `contentSha256`, отклонение конфликтующего содержимого, чтение существующих Git blobs и обработка данных в существующих путях хранения не изменялись.

## Проверенные сценарии

- `operation-prefix` не находит коммит с `Operation-Id: operation-prefix-long`.
- `operation-prefix-long` не находит коммит с `Operation-Id: operation-prefix`.
- Полный ID находит исходный коммит.
- Отсутствующий ID возвращает `null`.
- Идемпотентный retry с тем же ID и содержимым возвращает SHA исходного коммита.
- Повторное использование того же ID с другим содержимым отклоняется.
- Unicode-содержимое проходит сохранение, чтение Git blob и проверку хеша в контрактных тестах.

## Ограничения и границы проверки

- Проверка выполнена локально на временных Git-репозиториях, создаваемых тестами.
- Реальный PostgreSQL стенд не запускался: **NOT_RUN**.
- Серверный/браузерный end-to-end сценарий не запускался: **NOT_RUN**.
- Сетевые, удалённые Git и deployment-сценарии не проверялись.
- Отдельный бинарный fixture не запускался; код чтения Git blobs и бинарный возврат из `readArtifact` не изменялись.
- Формат трейлеров проверен в текущем виде `Operation-Id: <id>`; изменение допустимых символов ID не входит в S-03.
