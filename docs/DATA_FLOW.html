Что важно про границы

Runner-контейнер с кодом агента подключён только к сети coreteams и не видит PostgreSQL: база живёт в отдельной сети db.

Runner сам подключается к backend (соединение 11), входящих портов у контейнера проекта нет.

Доступ backend к docker.sock равен root на хосте; для production нужен docker-socket-proxy.

Лимиты с пометкой «умолч.» не заданы в проекте явно и берутся из библиотек.
