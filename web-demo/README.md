# CoreTeams — веб-прототип эпика 2.5

Интерактивное демо пользовательского пути CoreTeams: от знакомства с сервисом и вопросов фасилитатора до формирования лендинга идеи, запуска разработки, доработки и выбора следующего шага.

## Посмотреть

- Публичная версия: https://coreteams-epic-25-demo-2026.mariellbnboehmjem96.chatgpt.site
- Самодостаточный файл: `CoreTeams-прототип.html`

## Запустить локально

Требуется Node.js 18 или новее.

```powershell
npm start
```

Откройте http://127.0.0.1:4173/.

Зависимости устанавливать не нужно: демо использует только стандартные возможности Node.js и браузера.

## Проверить

```powershell
npm test
```

Тесты проверяют изоляцию проектов и гарантируют, что неизвестный исход работы не будет показан как успешно завершённый.

## Структура

- `public/` — интерфейс прототипа;
- `server.js` — локальный сервер и демонстрационный API;
- `test/` — автоматические проверки;
- `ОПИСАНИЕ-ПРОТОТИПА.md` — полный пользовательский сценарий и ограничения;
- `ARCHITECTURE.md` — техническая схема демо;
- `CoreTeams-прототип.html` — версия для открытия без сервера.

## Ограничения

Регистрация, работа ИИ-агентов, отправка писем, биллинг и публикация материалов внутри продукта пока имитируются. Интерфейс явно сообщает об этих ограничениях и не передаёт пользовательские данные третьим лицам.
