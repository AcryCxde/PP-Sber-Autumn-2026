# CoreTeams — веб-прототип эпика 2.5

Актуальная локальная версия — **v9, исправленный общий сценарий**. Пользователь приносит задачу, передаёт контекст и материалы, отвечает на три вопроса, рассматривает предложенную команду, согласует план и получает три последовательно одобряемых результата. Курс — один из сценариев, наряду с книгой, бизнес-идеей и произвольной задачей.

Экран команды объясняет необходимость, ответственность и передачу результатов каждой роли. Состав выбирается по демонстрационным правилам направления; выбор продвижения в бизнес-сценарии добавляет маркетолога. Произвольное описание не классифицируется ИИ. Роли не создаются и не запускаются в CTF; схема специализации или новой роли — предложение, которое ещё предстоит реализовать и проверить на сервере.

Позиционирование сохраняется: CoreTeams организует команду вокруг задачи пользователя. V9 пересматривает пользовательский путь и визуальную иерархию; операторская сохранена в v8.

## Запустить локально

Требуется Node.js 18 или новее.

```powershell
npm start
```

Откройте http://127.0.0.1:4173/.

V9 также доступна по `/v9`, прежний интерфейс — по `/v8`.

Зависимости устанавливать не нужно: демо использует только стандартные возможности Node.js и браузера.

## Проверить

Сборка автономной v9 и проверка встроенных ресурсов:

```powershell
npm run build:standalone
npm run verify:v9
```

Сборка включает изображения, видео и четыре локальных начертания/набора шрифта. Размер HTML около 30 МиБ. Проверка подтверждает синтаксис встроенного JS и отсутствие внешних ссылок на локальные ресурсы, но не заменяет проверку интерфейса в браузере.

Существующие тесты демонстрационного API:

```powershell
npm test
```

Тесты проверяют изоляцию проектов и гарантируют, что неизвестный исход работы не будет показан как успешно завершённый.

## Структура

- `public/v9/` — актуальный пользовательский интерфейс;
- `public/assets/v9/` — кадры из ролика и локальные шрифты с лицензией;
- `public/index.html`, `public/app.js`, `public/*.css` — прежний интерфейс v8, включая операторскую;
- `build-v9.mjs`, `verify-v9.mjs` — автономная сборка и её проверка;
- `server.js` — локальный сервер и демонстрационный API;
- `test/` — автоматические проверки;
- `ОПИСАНИЕ-ПРОТОТИПА.md` — полный пользовательский сценарий и ограничения;
- `ARCHITECTURE.md` — техническая схема демо;
- `CoreTeams-прототип.html` — версия для открытия без сервера.

## Ограничения

Регистрация, работа ИИ-агентов, отправка писем, биллинг и публикация материалов внутри продукта пока имитируются. Интерфейс явно сообщает об этих ограничениях и не передаёт пользовательские данные третьим лицам.

V9 не вызывает серверный API: хранит проекты отдельно в `localStorage` под ключом `coreteams-v9`, лимит — 3 проекта. Файлы сохраняются только как метаданные; их содержимое не читается. Ответы команды детерминированы. Замечание к доработке и контекст фиксируются в новой версии, но свободная генерация текста не подключена. Данные v8 автоматически не мигрируются.
