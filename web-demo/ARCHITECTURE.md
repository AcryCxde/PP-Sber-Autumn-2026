# Архитектура демо этапа A

```text
Browser → Node.js BFF → file state store
                     ↘ Run adapter (сейчас имитация)
```

Публичный интерфейс получает только канонические события. Исполнитель не пишет артефакт напрямую: сервер создаёт версию Markdown и только затем выдаёт `artifact_saved` и `completed`.

## Статус решений

| Область | Решение для стенда | Статус |
|---|---|---|
| UI и API | Node.js standard library + SSE | работает локально |
| Состояние/артефакт | JSON за пределами исполнителя | ограничено: подходит только для single-user демо |
| Изоляция проектов | серверная проверка владельца demo-user | работает для двух тестовых проектов |
| Run | имитация с честными outcome | заглушка |
| Контейнер | Docker daemon недоступен | не реализовано |
| Model gateway | не вызывается | не реализовано |

Нельзя показывать этот стенд как подтверждение контейнерной изоляции, вызова модели, расхода реальной валюты или production-устойчивости.
