# 2.5-8. Безопасные ошибки

| Ситуация | Текст пользователю | Что не показываем |
|---|---|---|
| Общая ошибка запуска | Работу не удалось завершить. Данные проекта и последняя подтверждённая версия сохранены. | Stack trace, stdout/stderr, имя контейнера |
| Исход неизвестен | Связь с исполнителем прервалась. Мы не помечаем работу завершённой, пока результат не подтверждён. | Сетевые адреса, gateway и внутренние retries |
| Недостаточный лимит | Доступного лимита недостаточно. Команда не запускалась и кредиты не списывались. | Внутреннюю формулу расчёта и ключи провайдера |
| Нет доступа | Проект недоступен или не существует. | Существует ли чужой проект и кто его владелец |
| Файл не поддерживается | Этот файл не удалось обработать. Добавьте PDF, DOCX, TXT, MD, PNG или JPG. | Парсер, системный путь и содержимое служебного лога |
| Сессия закончилась | Сессия завершилась. Войдите снова — сохранённые проекты останутся доступны. | Токен и причина серверной проверки |
| Конфликт версии | Результат изменился в другой вкладке. Обновите проект и повторите действие. | Внутренние ID версии и структуру БД |
| Сервис временно недоступен | Сейчас не удаётся продолжить работу. Попробуйте позже; сохранённые данные не потеряны. | Провайдера модели и инфраструктурную топологию |

## Проверка текста

Сообщение отвечает на три вопроса: что произошло, сохранены ли данные, что можно сделать дальше. Оно не обещает успех без подтверждения и не раскрывает внутреннее устройство.
