# CoreTeams: от задачи по продукту к проверяемому решению

Опишите продукт и решение, которое нужно принять или проверить. CoreTeams задаст уточняющие вопросы по одному, предложит команду и план, соберёт общий результат с основаниями, допущениями, картой гипотез и первым шагом. После результата можно обсудить новые условия и получить следующую версию. Для технической роли предусмотрен черновик скилла в архиве.

Это отдельный React-прототип направления 2.5 от 11 ноября 2026 года. Он расположен рядом с существующим `web-product`, чтобы React B из чернового запроса #11 и вариант A оставались доступными для сравнения. `reference.html` — автономный снимок HTML, который можно открыть без сборки.

## Запуск

Нужны Node.js 22.12+ и pnpm. В этой папке:

```sh
pnpm install --frozen-lockfile
pnpm dev
```

Открыть `http://127.0.0.1:4195/`.

Проверка модели и сборка:

```sh
pnpm test
pnpm build
```

Если в ограниченной среде Vite не может создать дочерний процесс для загрузки конфигурации, выполните `pnpm exec vite build --configLoader native`. Для этой ветки проверка типов, четыре проверки модели и сборка с `--configLoader native` пройдены.

## Что можно посмотреть

- Вход сразу в рабочее пространство. Роль выбирается для каждого нового проекта: «Владелец решения» или «Ответственный за реализацию».
- Один вопрос фасилитатора за раз, ответ по Enter, вложение через скрепку. В этом макете файл выбирается, но не загружается и не анализируется.
- Состав команды и план можно поправить. Схема передачи между ролями показывает согласованный план, а не реальную работу агентов.
- У ответственного за реализацию можно выбрать черновик скилла с `SKILL.md`, посмотреть его в отдельном окне и скачать архив.
- Документ результата открывается в отдельном окне; локально создаются PDF, DOCX, PPTX, XLSX и MD. Карта гипотез и первый шаг находятся внутри общего результата.
- Проекты и версии живут только в хранилище этого браузера. Доступны список, возврат к проекту, корзина и восстановление; предел — пять активных проектов.
- Регистрация и вход показаны как сценарий, но аккаунт не создаётся. Текст соглашения — проект для утверждения.

Прототип не подключён к шлюзу, исполнителю, серверному хранению и оплате. Число демо-кредитов не утверждено. Не используйте этот интерфейс как свидетельство анализа файлов, запуска ролей или серверного сохранения.

## Проверенный проход

Проверены две роли на широком экране, путь владельца на ширине 390 px, основные экраны на 320 px, редактирование состава и плана, скачивание PDF и восстановление результата после перезагрузки. Внешний полный проход с реальными сервисами и форматами файлов требуется отдельно.

Состав будущего сервиса и технические задачи описаны в `docs/2.5/coreteams-product-web-implementation-2026-11-11.md` от корня репозитория.
