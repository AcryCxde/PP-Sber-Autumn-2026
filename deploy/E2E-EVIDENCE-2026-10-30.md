# Доказательства первых E2E-прогонов

Дата: 30.10.2026. Статус: предварительный разбор результатов трёх прогонов на демо-стенде.

## Что наблюдалось

Три выгрузки результата показывают, что сервис сформировал структурированные тексты для разных типов задач:

| Код | Задача | Наблюдаемый результат | Показатели интерфейса, сообщённые владельцем |
| --- | --- | --- | --- |
| E2E-R | Предприятие по роботам-навигаторам | Карта гипотез, план проверки и бриф эксперимента; версии отмечены как одобренные | `$0.77`, `8 мин`, `5 запусков` |
| E2E-S | Скилл для работы с презентациями | Карта задачи, план и бриф; версии отмечены как одобренные | `$0.39`, `3 мин`, `5 запусков` |
| E2E-L | Этикетирование круглой и квадратной тары | Карта задачи, план и бриф; версии отмечены как одобренные | `$0.38`, `3 мин`, `4 запуска` |

Это подтверждает прохождение демо-пути до отображаемого результата на трёх разных задачах. Числа выше являются показаниями интерфейса; они не интерпретируются как активное время человека, измеренный выигрыш или тариф.

## Чего выгрузки не доказывают

В полученных Markdown-экспортах отсутствуют Run ID, SHA совместимых компонентов, журнал событий, подтверждение durable save, ZIP, restart/reopen и заметки сессий. Все три экспорта указывают, что материалы не добавлены.

Поэтому их нельзя использовать как единственное доказательство следующих границ:

| Проверка | Статус по этим выгрузкам | Нужное дополнительное доказательство |
| --- | --- | --- |
| `web → gateway → runner → storage → web` | не подтверждено | URL стенда, SHA, Run ID и обезличенный журнал событий |
| Вопрос и ответ продолжают тот же Run | не подтверждено | запись question/answer с одним Run ID |
| Подтверждённое сохранение версии | не подтверждено | receipt, artifact/version ID, readback и hash |
| ZIP и повторное открытие после restart | не подтверждено | ZIP, проверка состава, restart/reopen и сверка версии |
| React B на общей ревизии | не подтверждено | URL/SHA React B и сквозной прогон через адаптер |
| Пользовательский эффект | не подтверждено | согласованный протокол, заметки сессии и сопоставимый baseline |

## Следующий технический протокол

Для каждого следующего прогона сохранить обезличенно: адрес стенда, SHA web/gateway/runner/storage, project ID, Run ID, event IDs, вопрос/ответ, receipt сохранения, artifact/version ID, hash, статус ZIP, результат restart/reopen и PASS/FAIL/NOT_RUN по каждому шагу. Не сохранять в этом репозитории персональные данные, исходные файлы участников, секреты или полные транскрипты.
