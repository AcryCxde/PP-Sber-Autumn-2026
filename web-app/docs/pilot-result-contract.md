# Pilot result contract for backend adaptation — Илья

Self-contained handoff from the reviewed pilot package, 2026-10-15. Proposed content/export contract; no CTF execution, participant session, recruitment or deployment has run. The candidate is a solo business/project owner making a bounded decision outside their expertise using verifiable external sources. It is a task hypothesis, not a validated market segment. Input is participant-selected, arbitrary and non-secret. Eligible willing participant and explicit session consent are still required. Prototype session requires DEPLOYMENT_READY and completed baseline of the same task; Филипп owns deployment readiness.

`result.md` (UTF-8) sections: Decision requested; Short answer (bounded or insufficient evidence); What the evidence says (inline stable source IDs); Comparison or reasoning (criteria, tradeoffs, disagreement); Unknowns and limitations; Recommended next step (label recommendation); Expert review/escalation; Contributions (automated analysis separately from verified human review); Sources. For inapplicable sections say Not applicable and why. Do not imply qualified human review without evidence. External factual claims need actual sources; no invented citations. Separate sourced facts, self-report, observed behavior, system measurement, assumption, interpretation, recommendation, counterfactual and unknown.

ZIP name: `coreteams_<project-id>_<task-id>_<run-id>_<phase>_<build-version>.zip`, using safe stable IDs. Members: `result.md`, `sources.csv`, `metadata.json`, `manifest.json`. Sources columns: source_id,title,publisher,author,published_at,accessed_at,url,claim_ids,source_type,limitations. Empty sources table is permitted only with valid header and explicit insufficient-evidence statement. No source snippets as evidence or underlying participant files without specific permission.

Metadata: project_id,task_id,run_id,phase (baseline|prototype),build_version,environment,created_at with timezone,operator_id,participant_id pseudonym if applicable,input_scope (non-confidential description),consent_status,consent_text_version,result_schema_version,limitations. Manifest lists payload members only, with filename/media type/byte length/SHA-256/schema version. **Exclude manifest.json itself: no self hash.** Hash exact archived bytes.

Server export checks before ack/download: required members parse/nonempty (except schema-valid empty sources); filename/metadata IDs/build/phase match; every external factual assertion maps to a real source ID/URL; access dates and limitations recorded; no orphan IDs; UTF-8 decoding; SHA-256 and byte lengths agree; no contacts/raw survey responses/identifying quotations/secrets/temp files/unapproved source documents. Reject invalid archive. WEB currently verifies MIME and ZIP signature only; full member/content validation is backend work, not claimed by this app.

Validation cases: complete sourced case with conflicting evidence; no sources → explicit limited result/empty table; hypothetical case → counterfactual, never baseline; high-stakes gap → professional escalation; metadata/hash/privacy mismatch → block export. No estimated research outcome or made-up measurements.

Research measurements are separate from browser telemetry: active/wait/pause intervals, sources/people consulted, AI prompts/iterations/latency only when actually used, errors/help/download/reopen, applicability/usefulness and source verification. Blank/unknown is not zero. Pair only same participant/task; repetition/learning prevents causal claims about time saved.
